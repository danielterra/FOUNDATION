### 1. **ESTABILIDADE: Reduzir Uso de `.unwrap()` e `panic!`** - ALTO
**Status**: PENDING
**Prioridade**: ALTA

**Problema**: 88 instâncias de `.unwrap()` em 13 arquivos podem crashar a aplicação.

**Arquivos Principais**:
- `src-tauri/src/eavto/store.rs:154-194` - Panics em parse failures
- `src-tauri/src/turtle/mod.rs:136-176` - Panics durante TTL parsing
- `src-tauri/src/ai/providers.rs:152` - `.unwrap_or()` em critical path

**Ação Necessária**:
```rust
// ANTES (crashes)
let value = string.parse::<i64>().unwrap();

// DEPOIS (handle error)
let value = string.parse::<i64>()
    .map_err(|e| OwlError::ValidationError(
        format!("Invalid integer value '{}': {}", string, e)
    ))?;
```

**Sub-tarefas**:
- [ ] Identificar todos os `.unwrap()` em critical paths
- [ ] Substituir por proper error handling com `?`
- [ ] Adicionar error recovery onde apropriado
- [ ] Testar cenários de erro

### 3. **PERFORMANCE: File I/O Síncrono em Contexto Async** - MÉDIO
**Status**: PENDING
**Prioridade**: MÉDIA

**Problema**: Upload de arquivos grandes (30MB+) pode travar UI.

**Arquivo**: `src-tauri/src/commands/chat.rs:105-126`

**Ação Necessária**:
```rust
use tokio::fs;

pub async fn chat__attach_file(...) -> Result<String, String> {
    // Ler arquivo ANTES do lock do banco
    let file_content = fs::read(&file_path).await
        .map_err(|e| format!("Failed to read file: {}", e))?;

    fs::copy(&file_path, &stored_path).await
        .map_err(|e| format!("Failed to copy file: {}", e))?;

    // Lock do banco APENAS para metadata
    executor.write(move |conn| {
        // Store metadata
    }).await
}
```

**Sub-tarefas**:
- [ ] Adicionar `tokio::fs` como dependência se necessário
- [ ] Substituir `std::fs` por `tokio::fs` em `chat.rs`
- [ ] Testar com arquivos grandes (50MB+)
- [ ] Verificar que UI não trava durante upload
